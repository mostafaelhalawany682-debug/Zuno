# ZUNO — تطبيق فيديوهات قصيرة

نسخة أولى عربية من تطبيق اجتماعي للمقاطع القصيرة مبنية بـFlutter وSupabase. ترتبط بالبيانات الحقيقية في مشروع ZUNO، وليست واجهة تجريبية ببيانات ثابتة.

## ما يعمل في النسخة الأولى

- إنشاء حساب بالبريد وكلمة المرور، تسجيل الدخول والخروج، وملف شخصي محفوظ في Supabase.
- خلاصة عمودية تشغّل مقاطع قاعدة البيانات؛ تبويب «لك» وتبويب «أتابع».
- اختيار فيديو من الهاتف ورفعه مع وصف إلى Supabase Storage.
- الإعجاب وإلغاء الإعجاب، قراءة التعليقات وإضافتها، ومتابعة الحسابات وإلغاء متابعتها.
- البحث عن حسابات ومقاطع، وتعديل الاسم الظاهر والنبذة.
- واجهة عربية من اليمين إلى اليسار، ورسائل انتظار/خطأ/حالة فارغة.

## مهم بخصوص الخصوصية

Bucket الفيديوهات عام كي تعمل روابط تشغيل المقاطع في الخلاصة؛ لذلك يستطيع أي شخص يملك رابط المقطع الوصول إليه. لا ترفع محتوى خاصًا أو لا توافق على نشره. الرفع والحذف في Storage مقيدان بمجلد صاحب الحساب، والحد الأقصى للملف 100 ميغابايت والأنواع MP4 وMOV وWebM.

## مشروع Supabase المرتبط

تم تطبيق ترحيل إنشاء ملف الحساب على مشروع ZUNO، وكذلك bucket الفيديوهات وسياسات متابعة/رفع المستخدمين. لا تعِد تشغيل الترحيلات يدويًا على المشروع المرتبط.

لتثبيت نسخة جديدة من قاعدة البيانات: نفّذ `schema.sql` على مشروع جديد، ثم طبّق ملفات `migrations/` بترتيبها. لا تستخدم `schema.sql` على المشروع المرتبط؛ استخدم migrations فقط عند إعداد مشروع آخر قائم.

## التشغيل محليًا

يتطلب Flutter وDart 3.3 أو أحدث. استخدم Project URL ومفتاح Supabase القابل للنشر فقط؛ لا تضع `service_role` أو أي مفتاح سرّي داخل تطبيق الهاتف.

```bash
flutter pub get
flutter run \
  --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
```

للاختبارات والتحقق:

```bash
flutter analyze
flutter test
```
